# Teeko 教材制作手册

Grok 把一份素材加工成可审阅的课程文件。Codex 检查内容与页面能否对应，接入课程目录和真实课堂。第一轮交付选一个主题、做两页、测试一次口头翻页。先参考[两页纸飞机样例](drafts/paper-glider/1/course.json)和[样例制作说明](drafts/paper-glider/1/AUTHOR-NOTES.md)。

## 1. 交付一个课程文件夹

```text
courses/drafts/<course-id>/<version>/
  course.json
  AUTHOR-NOTES.md
  assets/
    page-one.svg
    page-two.svg
```

- `course.json` 写首页介绍、词汇、教学目标、教材页和按顺序排列的教学环节。字段沿用应用的 [PublishedCourse](../lib/classroom-contract.ts) 和 [页面、元素、环节定义](../lib/types.ts)。
- `AUTHOR-NOTES.md` 写选题理由、目标年龄、英语难度及依据。新闻课还要写原始链接、核对日期、哪些是来源事实、哪些是教学改写，以及每张图的作者或授权。每轮修改保留简短的变更说明。
- `assets/` 放原创或已取得再分发权限的素材。每页交付静态 SVG、PNG、WebP 或 JPEG，尺寸与 `width`、`height` 一致。SVG 使用本地绘制元素和文字。课程图片的应用路径写成 `/course-assets/<course-id>/<version>/<文件名>`。审核接入时，应用端把素材复制到对应的 `public/course-assets/` 目录。
- `course-id`、页面 ID、元素 ID、环节 ID 用小写英文、数字和连字符。版本从字符串 `"1"` 开始。已发布的内容需要修改时，建立新版本。

## 2. 给老师一张元素地图

整页上凡是老师要指给孩子看的内容，都可以定义成元素。例如标题、一段正文、一个关键词、整张插图、图中的翅膀。按教学需要选择粒度，一段值得带读的文字可以是一个元素，其中需要单独解释的词也可以有自己的元素。

每个元素填写 `id`、英文 `label`、中文 `chinese` 和 `box`。`box` 的 `x`、`y` 是左上角，`w`、`h` 是宽高，四个数都以整页宽高为基准。例如 `x: 0.2` 代表从页面左侧起 20% 的位置。应用根据当前页及元素 ID 找到目标，按屏幕实际尺寸绘制圈选。可预留更细的元素供后续文字高亮和下划线适配。

每个环节的 `pageId` 指向当前页。`targetId` 可以填该页一个主要目标，或留为 `null`。需要标注多个元素时，在教案中明确写出它们的 ID 和顺序。页面、目标和实际图片要一起复核。

## 3. 写给实时老师的教案

一个活动写一种意图，例如看图预测、读一段、解释一个词、讨论一个想法。每个环节交付这些内容。

| 字段 | 写什么 |
| --- | --- |
| `english` / `chinese` | 英文开场示例及简短中文环节名。用 `speak` 引导学员开口，最后的开放交流可以用 `listen` 配 `chat`。 |
| `reading.passage` | 本环节讲的短材料，用原创表达解释新闻事实。与页面可见文字核对，至多 500 字符。 |
| `reading.goal` | 本轮只做成一件事，至多 260 字符。 |
| `reading.teacherNotes` | 先讲什么、讲到哪里时标注哪个 ID、怎样接住插话并回到本环节，至多 380 字符。 |
| `reading.followUp` / `hint` | 一个能用语音回答的追问，以及一句孩子沉默时可用的示范，追问至多 160 字符。示范在应用中由课堂节奏决定何时使用。 |
| `expected` | 开放式口语活动填 `null`，允许合理的不同回答。 |

给 8–13 岁孩子选有画面感的材料，按英语基础决定句长和词汇。老师先简短打招呼，再主动讲一个看得见的细节，一次只问一个具体问题。学生可直接开口提问、回答或说继续。把新闻事实、预测和想象分开。学生没有开口时，可给一个短示范再邀请交流，留出思考时间。

应用管理老师人设、当前页教案、工具注册、标注确认和翻页。教案里的标注指令表达教学意图。当前 GPT Live 的主动圈图已接入机器人第一页翅膀，新课的元素和活动还需要应用侧接入及验证。

## 4. 交接与验收

1. Grok 提交一个版本目录，附上想给老师演示的目标 ID、开场、追问和口头翻页场景。
2. Codex 先在项目根目录运行本地检查，更换路径即可检查其他草稿。

   ```sh
   npm run courses:check -- courses/drafts/paper-glider/1
   ```

3. Codex 对照页面看标注位置和文字可读性，核对事实与素材许可，再把选定版本加入应用目录。授权待核实的内容留在本地审阅。
4. 在真实语音课堂逐项确认老师能讲到页面内容、标注出现、能接住学生插话并在应用确认后翻页。文件检查通过与真实课堂验收分别记录。

## 给 Grok 的首轮任务

> 请按本手册做一份两页的 Teeko 主题草稿。选一个来源可核对、适合 8–13 岁的英语新闻主题，按目标英语难度改写，并用自己的文字和可再分发的图片。第一页看图、讲一个核心事实、聊一个预测。第二页读一小段、解释一个词、聊一个开放问题。每页选一至三个老师确实会标注的元素。每个活动写清要讲什么、讲到哪里标注哪个元素、孩子没回答时怎么帮一句。学生只用语音互动。交付 `course.json`、`AUTHOR-NOTES.md` 和 `assets/`，并列出首轮验证的两个目标及口头翻页场景。
